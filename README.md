# API REST Materias

API REST desarrollada con Node.js y Express para Programación IV.

## Tecnologías utilizadas

- Node.js
- Express
- Dotenv
- Nodemon

## Endpoints

GET /api/materias

GET /api/materias/:id

POST /api/materias

PUT /api/materias/:id

DELETE /api/materias/:id
